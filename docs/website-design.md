# Website Design

This is a cereal review website which will be used to document our journey through all the cereals that exist in the cereal aisle.

The vision is for the website to load up and be a view of a cereal box. Tilted ever so slightly off the the side and viewed a tiny bit from above so that you can "See" the left side and top side of the box a little bit. The top side of the box contains the site menu

90s theme
